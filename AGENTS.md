## Loop Engineering

This project runs goals through a Loop controller. Current status: `.loop/STATUS.md`.
Use the `loop` MCP tools if your tool supports MCP (see `.mcp.json`); otherwise use the CLI `.loop/bin/loop` (`next`, `plan`, `task done`, `check`, `note`, `ask`, `finish`, `status`).
Start each turn with `loop next`, record a handoff note before you stop, never edit `.loop/` by hand, and never weaken checks. Full guide: `.agents/skills/loop/SKILL.md` or `.claude/skills/loop/SKILL.md`.

## 可复算工作负载

假设每次模型调用 8,000 输入、2,000 输出 token；每个 Task 4 次调用；无缓存、工具、搜索、图像、音频或额外服务。单次=(8000×输入价+2000×输出价)/1000000；每 Task=单次×4。

| 模型 | 单次调用 | 每 Task | 100 个 Task（400 次调用） |
| --- | ---: | ---: | ---: |
| gpt-6-luna | $0.0018 | $0.0072 | $0.72 |
| gpt-6.1-sol | $0.036 | $0.144 | $14.40 |
| gpt-6-astra | $0.18 | $0.72 | $72.00 |

若 100 Task 中 90 用 Luna、10 用 Sol，估算=90×0.0072+10×0.144=$2.088。预留 50% 重试/输出波动余量为 $3.132。这是固定 token 假设情景，不是实际账单；真实代理循环轮数、上下文、推理输出、重试可能显著增加。

若有缓存，公式应分别加计 未缓存输入×输入价 + 缓存命中×缓存输入价 + 缓存写入×写入价 + 输出×输出价；本表不声称实际已获得缓存。搜索/存储/网络/音频/图像/托管/第三方网关与税费单独核对。

Agent Fabric: design foundations

One system for iPhone, Android, iPad, Android tablet, Mac and Windows. Same objects and tokens everywhere; layout and navigation adapt to the device.
Principles
No surprise
No unexpected action, audience, computer, cost or publication. Each is shown before it happens.
Server is the truth
Every screen shows how fresh it is. A stale view never blocks Stop.
Facts stay separate
Draft, checked, accepted and delivered are four different statuses, never one Completed.
Five objects, everywhere
Space, Conversation, Task, Computer, Result. Phone and desktop use the same names.

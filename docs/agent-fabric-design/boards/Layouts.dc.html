Three layout classes cover six platforms

Layout follows window width, not brand of device. Platform differences are limited to navigation placement, back behaviour, system prompts and input.
Compact · under 600
iPhone, Android phone
One pane. Bottom navigation: Home, Spaces, Inbox. Space tabs on top: Chat, Work, Files, Computer. Detail opens as a screen.
Medium · 600 to 1000
iPad portrait, Android tablet portrait
Navigation rail plus one main pane; the detail pane slides over as a sheet and can pin beside the list.
Expanded · 1000 and up
iPad landscape, tablets, Mac, Windows
Sidebar, list, detail and an optional context panel. Dense work (canvas edits, code review, telemetry) lives here.

# G1-F04 deterministic model contracts

Additive native composition under the approved [F04 plan](../docs/planning/g1-f04-plan.md). This package supplies f04-01 contracts/build/verification boundaries, f04-02 independent receipt adapter/owned fixture, f04-03 profile/context/qualification/proposal boundaries, f04-04 shared ledger/immutable intent/one-use claim primitives, f04-05 coordinated retry/original-owner usage/deficit settlement, f04-06 native SessionLoop/operator/wait/Stop/output composition, and f04-07 synthetic resource interval/lifecycle accounting. The eight acceptance suites are later task deliverables. Component diagnostics do not establish aggregate acceptance.

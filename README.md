# agent-fabric

Agent Fabric 是以自有原生引擎、持久远端 Space 和跨设备客户端为核心的拟议企业代理平台。

当前仓库保存产品规格、设计输入和工程计划；尚无可运行产品。本批只形成路线图及 G0 实施计划，G0 产品实现与资格验证尚未开展。
